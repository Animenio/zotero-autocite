# Short demo script (60–90 seconds)

Purpose: show real behavior, not a rendered mockup. Record the screen with a disposable Zotero test library/collection, hiding local file paths, email addresses, sensitive projects, and private Zotero records.

| Time | On-screen action | Voiceover focus |
|---|---|---|
| 0–12 s | Show a manuscript containing `[[Z:...]]` and `[[ZBIB]]` | The problem: citations are currently unlinked text |
| 12–28 s | Search a DOI in AutoCite and verify metadata | DOI-first lookup and source identity verification |
| 28–40 s | Register and copy the short alias | Stable local mapping, not a universal DOI replacement |
| 40–55 s | Select Zotero test collection and convert the original Word file | Authorized import and copy-based document processing |
| 55–72 s | Open generated DOCX and choose Zotero → Refresh | Live Zotero citations and a single bibliography entry |
| 72–83 s | Choose Add/Edit Citation on a converted field | Editable linked citation, not only formatted text |
| 83–90 s | Show CSV log and GitHub repository | Transparency, beta scope and request for developer feedback |

Avoid claiming "native Word integration", "instant Refresh conversion", or "fully automatic verification of scientific claims": these are not implemented.
