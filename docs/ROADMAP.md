# Proposed roadmap

## v0.5 — proof of concept (current)

- Windows Tkinter app
- DOI-first metadata search and verification
- Local SQLite alias registry and CSV export
- User-selected Zotero import collection
- Copy-based Word conversion with Zotero fields
- Logs and a manual Zotero Refresh step
- Optional VBA launcher

## v0.6 — native authoring workflow (proposed)

- In-place conversion of the **currently open** Word document with a safe undo/backup strategy.
- A dedicated Word ribbon command (not a modification of Zotero's native Refresh button).
- Confirmed, supported invocation of Zotero field refresh when technically possible.
- Protected conversion of complex run/field layouts.

## v0.7 — citation syntax (proposed)

- Narrative citations and multi-source clusters in one Zotero citation.
- Locator fields/pages, prefixes/suffixes, suppressed authors.
- Better error disambiguation UI and source previews.

## v0.8 — interoperability (proposed)

- Better BibTeX/Zotero key import/export and collision-safe portable mappings.
- Document-level embedded alias manifests or sidecars.
- Comprehensive Word/Zotero version matrix, security assessment, packaging/signing.

These are **plans**, not implemented features or a release commitment.
